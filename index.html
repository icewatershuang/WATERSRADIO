版权声明

本程序的界面设计、代码实现与电台库整理均由作者独立完成。

电台流地址来自公开互联网资源，版权归原作者或播出机构所有；本程序仅提供播放界面，不存储、不分发任何音频内容。

HLS 解析由 hls.js（Apache-2.0）提供。

技术栈

单文件 HTML + CSS + 原生 JavaScript，无任何框架依赖；离线可用。

Android 版基于系统 WebView，前台服务 + MediaSession 实现锁屏播放与蓝牙遥控。

数据与隐私

所有收藏、订阅、设置仅保存在本机浏览器（LocalStorage），不上传任何服务器。

换设备前请用「设置 → 备份」导出数据。
